# CQ Common Scenarios

## UI/UX Changes
**Trigger**: "improve the UI", "make it better", "fix the layout"

**Standard CQs**:
1. What specific aspect needs improvement?
   a. Visual appearance/styling
   b. User interaction/functionality
   c. Layout/positioning
   d. Performance/responsiveness

2. What is the priority level?
   a. Critical bug affecting usability
   b. Enhancement for better UX
   c. Nice-to-have improvement
   d. Experimental/testing change

## Bug Fixes
**Trigger**: "fix this", "it's broken", "not working"

**Standard CQs**:
1. What is the expected behavior?
   a. Specific function should work differently
   b. Visual element should appear/position differently
   c. Data should be processed/displayed differently
   d. User interaction should respond differently

2. What is the scope of testing needed?
   a. Just the specific fix
   b. Related functionality
   c. Full regression testing
   d. User acceptance testing

## Feature Implementation
**Trigger**: "add feature", "implement", "create new"

**Standard CQs**:
1. What is the primary use case?
   a. User workflow enhancement
   b. Data processing capability
   c. Integration with external system
   d. Performance optimization

2. What are the constraints?
   a. Must work within existing architecture
   b. Performance requirements
   c. Browser compatibility needs
   d. Timeline limitations

## Code Organization
**Trigger**: "refactor", "reorganize", "clean up"

**Standard CQs**:
1. What is the main goal?
   a. Improve code readability
   b. Enhance performance
   c. Reduce complexity
   d. Prepare for new features

2. What should be preserved?
   a. All existing functionality
   b. Current API interfaces
   c. Performance characteristics
   d. Specific implementation details
